🎯 Number Guessing Game (C)
A simple, interactive CLI game where the player tries to guess a randomly generated number between 1 and 100.

Features
Randomized Gameplay: New number every session using srand().

Real-time Hints: Tells you to go "Higher" or "Lower."

Attempt Tracker: Displays total guesses upon winning.

🛠️ Logic Used
Loops: do-while for continuous gameplay.

Conditions: if-else for logic branching.

Library: <time.h> for true randomization.

Quick Start
Bash
gcc main.c -o game
./game
